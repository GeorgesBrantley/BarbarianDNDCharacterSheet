# Experiment Barbarian Field Sheet

A dependency-free local DND session helper for an Experiment Barbarian: HP, rage, attacks, stats, skills, inventory, potions, statuses, and categorized notes.

Open `index.html` directly in a browser, or host it locally from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

Your sheet saves automatically in the browser with `localStorage`. Use **Export to Saves** and select either this project folder or its `Saves` folder when prompted. Browsers that do not support direct folder access fall back to the Downloads folder. Use Import to restore or move character data.
